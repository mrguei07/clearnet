## 1. Constats & Avis stratégique

| Force (validée dans le code V1.3) | Limite stratégique | Verrou commercial |
| :--- | :--- | :--- |
| BullMQ robuste : retries exp. (5×5 s), événement `failed` → audit `FailedJob` (Neo4j) + Slack | **Pas d'admin UI** : un ops ne peut ni lister ni relancer un job en échec | SLA & autonomie ops |
| 15 secteurs, quota/multi-secteurs, échanges versionnés | **Paiement manuel** : pas de freemium → Pro → Enterprise verrouillé par code | Monetisation Série A |
| Mobile offline-first (expo-sqlite + NetInfo + socket.io `transaction:status`) | **Tests E2E manuels** : régression possible sur sync offline & WebSocket | Confiance des early adopters |
| Flags `*_ENABLED` off par défaut, secrets externalisés (existingSecret/SealedSecrets) | **Backend = opérateur unique** (`BLOCKCHAIN_PRIVATE_KEY` signe `settle`/`mint`) | Bloquant clients régulés (Défense, Finance) |
| Grafana prêt (12 panneaux, schemaVersion 39) | **Pas de `/metrics` Prometheus** ni alertes (échecs > 5 % invisibles) | Fiabilité & SRE |

**Avis stratégique** : V1.3 est un moteur de règlement fiable et auditable (le « train »).
V1.4 est le **système de conduite et de monétisation** : cockpit ops (Axe 1), caisse
(Axe 2), crash-tests automatiques (Axe 3), délégation de signature (Axe 4), instruments
de bord (Axe 5). Chaque axe est **désactivable individuellement** (règle d'or V1.3
conservée), ne modifie **aucun contrat existant** (Axe 4 = transfert d'ownership, pas de
changement de `CompensationEngine.sol`) et s'intègre au chart Helm existant sans breaking.

**Ordre d'exécution recommandé (13 jours ouvrables)** :

| Jour | Lot | Sortie |
|---|---|---|
| J1–J2 | Axe 5 (métriques) + **3.4 (métriques on-chain)** + **3.1 (monitor multisig PENDING)** + Axe 1 (admin) | `/metrics` + alertes BullMQ/on-chain/multisig, admin DLQ verts |
| J3–J5 | Axe 2 (billing Stripe) + **3.5 (IP allowlist)** + **3.2 (alerte 80 %)** + **3.6 (early adopters)** | Checkout + webhook synchronisés, quota FREE, exemptions |

### AXE 1 — Interface d'administration des échecs (DLQ & Retry)

**Problème** : les jobs échoués sont visibles (Neo4j `FailedJob`, Slack) mais pas actionnables.

**Solution** : module `AdminModule` protégé par un nouveau garde de rôle (vérification faite :
**`roles.guard.ts` n'existe pas** dans `src/common/guards/` — il est créé). Rôle déterminé
par appartenance à la liste `ADMIN_EMAILS` (le payload JWT V1.3 `{sub, email}` ne contient
pas de rôle : on ne touche pas au flux d'authentification → rétrocompatibilité).

| Sous-tâche | Fichier | Type |
|---|---|---|
| 1.1 | `clearnet-backend/src/common/guards/roles.guard.ts` | [N] — garde `@Roles('admin')` + décorateur `@Roles()` dans le même fichier |
| 1.2 | `clearnet-backend/src/admin/admin.module.ts` | [N] — module conditionnel (même motif que TransactionsModule) |
| 1.3 | `clearnet-backend/src/admin/admin.controller.ts` | [N] — 4 routes (+1 bonus audit) |
| 1.4 | `clearnet-backend/src/admin/admin.service.ts` | [N] — logique queue + requête Cypher `FailedJob` |
| 1.5 | `clearnet-backend/src/transactions/transaction.processor.ts` | [M] — `export const ONCHAIN_QUEUE` réutilisé ; getter `getQueue()` sur le processor (voir diff Annexe A) |
| 1.6 | `clearnet-backend/src/app.module.ts` | [M] — import `AdminModule` |
| 1.7 | `clearnet-backend/.env.example` + chart | [E] `ADMIN_EMAILS=` (vide = admin désactivé) |

**Routes** :

| Méthode | Route | Garde | Comportement |
|---|---|---|---|
| GET | `/api/admin/queue/failed?page=1&limit=20` | JWT + admin | 200 `{items, total, page, limit}` ; **503** si `QUEUE_ENABLED=false` (« queue disabled ») |
| POST | `/api/admin/queue/retry/:jobId` | JWT + admin | relance `job.retry()` (conservation des attempts déjà consommés) ; 404 si job inconnu |
| DELETE | `/api/admin/queue/clean/:queue` | JWT + admin | `queue.obliterate({ force: true })` ; `:queue` limité à `onchain-settlement` (whitelist dure) |
| GET | `/api/admin/queue/failed-audit?page&limit` | JWT + admin | bonus : audit durable Neo4j (`FailedJob` nodes), **fonctionne aussi file désactivée** |

**Rétrocompatibilité** : si `QUEUE_ENABLED=false`, `AdminModule` ne s'enregistre que si le
flag est actif (le DELETE/GET renvoient 503 explicite) ; l'audit Neo4j (1er bonus) reste
disponible — ce qui préserve le comportement V1.3 (dégradation douce) et l'évaluation
dynamique du flag à chaque appel.

**Commandes** :
```bash
cd clearnet-backend
npm run build
npm run test            # 13 tests V1.3 + roles.guard.spec + admin.controller.spec
```

### AXE 2 — Module de facturation (Stripe / Freemium)

**Problème** : tarification manuelle (commission 0,7 %), aucun verrou fonctionnel.

**Solution** : SDK Stripe côté backend, checkout hébergé (pas de PCI à gérer), webhook
signé pour synchroniser `subscriptionTier` sur le nœud `User` (Neo4j), quota FREE dans
`TransactionsService`.

| Sous-tâche | Fichier | Type |
|---|---|---|
| 2.1 | `clearnet-backend/package.json` | [M] `+ stripe` (`npm i stripe`) |
| 2.2 | `clearnet-backend/src/billing/billing.module.ts` | [N] |
| 2.3 | `clearnet-backend/src/billing/billing.service.ts` | [N] — Stripe client + mapping tier |
| 2.4 | `clearnet-backend/src/billing/billing.controller.ts` | [N] — `POST /billing/create-checkout`, `GET /billing/status` |
| 2.5 | `clearnet-backend/src/billing/webhooks/stripe.webhook.controller.ts` | [N] — raw body + signature |
| 2.6 | `clearnet-backend/src/auth/auth.service.ts` | [M] — création du nœud User : `subscriptionTier: 'FREE'` par défaut (diff Annexe B) |
| 2.7 | `clearnet-backend/src/transactions/transactions.service.ts` | [M] — garde de quota FREE (diff Annexe B) |
| 2.8 | `clearnet-mobile/src/screens/BillingScreen.tsx` | [N] — statut + lien checkout (deep link `clearnet://billing`) |
| 2.9 | `.env.example` + chart + values-production | [E] `BILLING_ENABLED`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRICE_PRO`, `BILLING_FREE_QUOTA=10` |

**Flux** :

```
POST /api/billing/create-checkout (JWT)
   → stripe.checkout.sessions.create({ mode:'subscription', customer_email,
       line_items:[{price: STRIPE_PRICE_PRO}], success_url, cancel_url })
   → { url }
POST /api/webhooks/stripe (signature `stripe.signature`)
   → constructEvent(rawBody, sig, STRIPE_WEBHOOK_SECRET)   [rejet si signature invalide]
   → subscription.created/updated/deleted
   → MATCH (u:User {email}) SET u.subscriptionTier = <PRO|FREE>, u.stripeCustomer = …
POST /api/transactions (JWT)
   → si BILLING_ENABLED && tier FREE && quota mensuel atteint  → 402 { code:'BILLING_QUOTA_EXCEEDED' }
```

**Quota FREE** : Cypher comptant les transactions du mois courant pour l'email
(`createdAt >= startOfMonth`) ; `FREE` ⇒ max `BILLING_FREE_QUOTA` (défaut 10 soit
31 requêtes/mois à 0,7 % ≈ revenu de démonstration négligeable) ; `PRO`/`ENTERPRISE`
illimités (seuil ENTERPRISE via `BILLING_ENTERPRISE_QUOTA`, défaut 0 = illimité).

**Rétrocompatibilité** : `BILLING_ENABLED` off par défaut → la garde de quota est un
**no-op strict** (le flux V1.3 reste identique) ; le nœud `User` gagne un champ sans
contrainte d'index (les requêtes existantes ne le sélectionnent pas).

### AXE 3 — Tests E2E Mobile automatisés (Maestro)

**Problème** : validation mobile manuelle (offline-first + socket.io à risque).

**Solution** : **Maestro** (YAML déclaratif, plus simple que Detox pour un stack Expo).

| Sous-tâche | Fichier | Type |
|---|---|---|
| 3.1 | `clearnet-mobile/.maestro/login.yaml` | [N] — inscription → connexion → écran accueil |
| 3.2 | `clearnet-mobile/.maestro/offline-sync.yaml` | [N] — tx hors-ligne → réactivation → sync → vérif WebSocket `transaction:status` = SUCCESS |
| 3.3 | `clearnet-mobile/src/**` (composants ciblés) | [M] — ajout de `testID` sur : email/password inputs, bouton envoi, toast, listes tx (nécessaire : Maestro ne cible que via `id`/`text`/`testID`) |
| 3.4 | `.github/workflows/mobile-ci.yml` | [N] — job : APK debug (Expo prebuild + gradle), émulateur Android, Maestro |
| 3.5 | `clearnet-mobile/scripts/maestro-local.ps1` | [N] — version Windows (parité avec CI) |

**Détail flows** (Annexe C, code complet) :
- `login.yaml` : lance l'app (`appId` com.clearnet.mobile), attend l'écran d'accueil,
  navigue Inscription, remplit `testID:register-email/register-password`, valide, attend
  `testID:home-screen` ; puis déconnexion/connexion avec le même compte.
- `offline-sync.yaml` : connexion réussie → `setAirplaneMode: true` → saisie d'une tx
  (montant 1.25, note `maestro-offline`) → **vérification d'un état local « en attente »**
  (expo-sqlite) → `setAirplaneMode: false` → attente toast **« Réseau rétabli »** →
  vérification du statut **SUCCESS** remonté par WebSocket (`transaction:status`) soit
  dans l'UI, soit via une assertion sur le toast de synchronisation.

**CI** (`mobile-ci.yml`) : runner `ubuntu-latest`, `reactivecircus/android-emulator-runner`@v2
(API 33, headless), build APK via `npx expo prebuild --platform android` + `./gradlew
assembleDebug` (job séparé, cache gradle), installation `curl -Ls
"https://get.maestro.mobile.dev" | bash` (version pinée `3.x`), `maestro test .maestro`.
**Temps estimé** : ~25–30 min par push (émulateur faible) → déclenchement `pull_request`
+ `schedule` hebdo + manuel (`workflow_dispatch`).

**Rétrocompatibilité** : aucun impact runtime (les `testID` ne changent pas le
comportement) ; les flows exigent un API Demo/local (variables `APP_HOST` injectées).

### AXE 4 — Délégation de la clé privée (Multi-sig 2/3 & HSM)

**Problème** : le backend détient `BLOCKCHAIN_PRIVATE_KEY` (contrôle total). Interdiction
formelle : **ne pas modifier `CompensationEngine.sol`** → la bascule se fait par
**transfert d'ownership OZ `Ownable.transferOwnership()`** vers le multisig, présent
dans tous les contrats existants (aucun diff Solidity requis).

**Solution V1.4 (light)** : **MultiSigWallet 2/3** (OpenZeppelin) + mécanique
« proposition » : le backend assemble la transaction mais ne l'exécute plus seul.

| Sous-tâche | Fichier | Type |
|---|---|---|
| 4.1 | `clearnet-blockchain/contracts/MultiSigWallet.sol` | [N] — OpenZeppelin, `submitTransaction/confirmTransaction/executeTransaction`, `REQUIRED` confirmations (2) |
| 4.2 | `clearnet-blockchain/scripts/deploy-multisig.js` | [N] — déploie le multisig avec les 3 owners (env `MULTISIG_OWNERS`), transfert ownership de ClearNetToken **et** CompensationEngine, écrit `deployments/sepolia.json` |
| 4.3 | `clearnet-blockchain/test/multisig.test.js` | [N] — 2/3 requis, rejet < 2 confirmations |
| 4.4 | `clearnet-backend/src/blockchain/blockchain.service.ts` | [M] — `settleCompensation` (ancre : ligne **290**) : si `MULTISIG_ENABLED`, **submitTransaction** (data = `settle(from,to,amount)`), pas d'exécution directe (diff Annexe D) |
| 4.5 | `clearnet-backend/src/signatures/signatures.module.ts` + controller + service | [N] — ledger d'approbation : `POST /api/signatures/request` (2FA d'appareil = code **HMAC-SHA256(secret, txId)** 6 chiffres via `SIGNATURE_2FA_SECRET`), `POST /api/signatures/:id/approve`, `GET /api/signatures/pending` |
| 4.6 | `clearnet-blockchain/scripts/multisig-approve.sh` + `.ps1` | [N] — opérateur 2ᵉ & 3ᵉ owner : `approveConfirm` + `executeTransaction` (clés **jamais copiées dans les logs** ; lecture via `MULTISIG_OWNER_KEY_2`/`_3` depuis l'env ou les secrets) |
| 4.7 | `.env.example` + chart | [E] `MULTISIG_ENABLED=false`, `MULTISIG_ADDRESS`, `MULTISIG_OWNERS`, `SIGNATURE_2FA_SECRET` |

**Flux** :

```
TransactionsService → settle (MULTISIG_ENABLED)
   → BlockchainService.submitSettlement(from,to,amount)
        data = encoder.encodeFunctionData('settle', [fromAddr, toAddr, amountWei])
        submitTransaction(COMPENSATION_ENGINE, 0, data)     (signé par owner 1 = backend)
        → txHash + onchainStatus='PENDING_MULTISIG' + onchainHash=txHash (Neo4j + WS)
   → ledger signatures : SignatureRequest {txId, dataDescription, createdBy, approvedBy[], status:'PENDING'}
Post /api/signatures/request            (admin 2FA)   → audit + rappel ops
scripts/multisig-approve.sh <txHash>    (owner 2)     → confirmTransaction → 1/2
scripts/multisig-approve.sh <txHash>    (owner 3 ou 2)→ confirmTransaction → 2/2 → executeTransaction
   → CompensationEngine: Compensated(from,to,amount)   → (poll backend) onchainStatus='SUCCESS' + WS
```

**Sécurité** : la clé backend ne peut plus **exécuter** seule un `settle` (elle ne fait
que soumettre) ; `mintTo` backé par les mêmes règles de soumission. Les clés owners 2/3
ne circulent que dans les scripts ops (jamais dans le chart, jamais dans les logs —
logs bornés à `txHash` et statut).

**Rétrocompatibilité** : `MULTISIG_ENABLED=false` → `settleCompensation` strictement
V1.3 (exécution directe) ; l'extension ZK (`settleWithProof`) reste branchée sur l'engine,
inchangée.

### 3.1 — Gouvernance des clés multisig (Axe 4) : garde-fous Phase 1 + monitor PENDING

**Risque** : clé owner 2/3 exposée dans l'historique bash ; owner absent → blocage.

**Phase 1 (V1.4)** :

| Sous-tâche | Fichier | Type |
|---|---|---|
| 3.1.1 | `clearnet-blockchain/scripts/multisig-approve.sh` (+`.ps1`) | [M] — **durcissement** : `unset HISTFILE` en tête, clés lues **uniquement** via `--key-file <chemin 0600>` (refus si perms trop ouvertes), **audit local** append-only `deployments/approval-audit.log` (`{ts, txId, operator, txHash}` — jamais de clé), procédure de **rotation** documentée en commentaire (`--rotate` = générer une nouvelle adresse owner + `addOwner` multisig) |
| 3.1.2 | `clearnet-backend/src/blockchain/multisig.monitor.ts` | [N] — **cron interne** (15 min, V1.4.0) : scan `transactionCount()` ; toute soumission non exécutée > `MULTISIG_PENDING_MAX_MS` (défaut **4 h**) → gauge `clearnet_multisig_pending_tx_seconds` + **notification Slack** (réutilise `SLACK_WEBHOOK_URL`) |
| 3.1.3 | `infrastructure/helm/clearnet/templates/backend-prometheusrule.yaml` | [M] — alerte `MultiSigStuckPending` (annexe E.6) |
| 3.1.4 | `clearnet-backend/src/metrics/metrics.providers.ts` | [M] — fournit le `Registry` prom-client aux modules blockchain (injection, règle d'or `METRICS_ENABLED`) |

**Phase 2 (V1.4.1, roadmap)** : owners 2/3 = comptes **Fireblocks** ou **AWS KMS**
(`kms-sign` via `JsonRpcSigner`/`SigningKey`) — le `MultiSigWallet` reste inchangé, seules
les adresses owners changent vers des clés jamais exposées à un humain.

```typescript
// src/blockchain/multisig.monitor.ts [N] — extrait (3.1.2)
@Injectable()
export class MultisigMonitor implements OnApplicationBootstrap, OnApplicationShutdown {
  private timer?: NodeJS.Timeout;
  private gauge?: Gauge;

  constructor(
    private readonly config: ConfigService,
    @Inject('MULTISIG_CONTRACT') private readonly multisig: Contract | null,
    @Inject(METRICS_REGISTRY) private readonly registry: any,
  ) {}

  onApplicationBootstrap() {
    if (this.config.get<string>('MULTISIG_ENABLED') !== 'true' || !this.multisig) return;
    if (this.config.get<string>('METRICS_ENABLED') === 'true') {
      this.gauge = new Gauge({
        name: 'clearnet_multisig_pending_tx_seconds',
        help: 'Âge (s) de la plus ancienne soumission multisig non exécutée',
        registers: [this.registry],
      });
    }
    this.timer = setInterval(() => void this.check(), 15 * 60_000);
  }

  private async check() {
    try {
      const n = Number(await this.multisig.transactionCount());
      let oldest: { id: number; ageSec: number } | null = null;
      for (let i = 0; i < n; i++) {
        const t = await this.multisig.transactions(i);
        if (t.executed) continue;
        const ageSec = Date.now() / 1000 - Number(t.timestamp);
        if (!oldest || ageSec > oldest.ageSec) oldest = { id: i, ageSec };
      }
      this.gauge?.set(oldest?.ageSec ?? 0);
      const max = Number(this.config.get<string>('MULTISIG_PENDING_MAX_MS', '14400000')) / 1000;
      if (oldest && oldest.ageSec > max) {
        this.logger.warn(`multisig tx #${oldest.id} non confirmée depuis ${Math.round(oldest.ageSec / 3600)} h`);
        await this.notifySlack(oldest);   // SLACK_WEBHOOK_URL (V1.3), non bloquant
      }
    } catch { /* réseau indisponible : dégradation douce */ }
  }

  private async notifySlack(t: { id: number; ageSec: number }) {
    const url = this.config.get<string>('SLACK_WEBHOOK_URL', '');
    if (!url) return;
    await fetch(url, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({
        text: `⚠️ ClearNet : soumission multisig #${t.id} non confirmée depuis ${Math.round(t.ageSec / 3600)} h — vérifier owners 2/3.`,
      }),
    }).catch(() => undefined);
  }

  onApplicationShutdown() { if (this.timer) clearInterval(this.timer); }
}
```

```typescript
@Injectable()
export class StripeIpGuard implements CanActivate {
  private cached: string[] | null = null;
  private cachedAt = 0;

  constructor(private readonly config: ConfigService) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    const env = this.config.get<string>('NODE_ENV', 'development');
    const req = context.switchToHttp().getRequest();
    const ip = String(req.ip ?? '').replace(/^::ffff:/, '');
    if (env !== 'production' && (ip === '127.0.0.1' || ip === '::1')) return true;

    const staticList = (this.config.get<string>('STRIPE_WEBHOOK_IPS', '') || '')
      .split(',').map((s) => s.trim()).filter(Boolean);

    if (Date.now() - this.cachedAt > 24 * 3_600_000) {
      try {
        const res = await fetch('https://stripe.com/files/ips/ips_webhooks.json');
        const data = (await res.json()) as { webhooks: string[] };
        this.cached = (data.webhooks ?? []).map((r) => r.split('/')[0]);
        this.cachedAt = Date.now();
      } catch { /* repli sur STRIPE_WEBHOOK_IPS */ }
    }
    const allowed = new Set([...staticList, ...(this.cached ?? [])]);
    if (allowed.size === 0) throw new ForbiddenException('stripe ips not configured'); // fail-closed
    if (!allowed.has(ip)) throw new ForbiddenException('ip not allowed');
    return true;
  }
}
```

```typescript
import { CanActivate, ExecutionContext, ForbiddenException, Injectable, SetMetadata } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { ConfigService } from '@nestjs/config';

/**
 * V1.4 - Garde de rôles. Le payload JWT V1.3 ({sub, email}) n'est pas modifié :
 * le rôle 'admin' est dérivé de l'appartenance à ADMIN_EMAILS (liste CSV dans
 * l'environnement, vide = aucun admin = garde inopérante).
 * Règle d'or : off par défaut.
 */
export const Roles = (...roles: string[]) => SetMetadata('roles', roles);

@Injectable()
export class RolesGuard implements CanActivate {
  constructor(
    private readonly reflector: Reflector,
    private readonly config: ConfigService,
  ) {}

  canActivate(context: ExecutionContext): boolean {
    const required = this.reflector.getAllAndOverride<string[]>('roles', [
      context.getHandler(),
      context.getClass(),
    ]);
    if (!required || required.length === 0) return true;

    const admins = (this.config.get<string>('ADMIN_EMAILS', '') || '')
      .split(',')
      .map((e) => e.trim().toLowerCase())
      .filter(Boolean);
    if (admins.length === 0) throw new ForbiddenException('admin feature disabled');

    const { user } = context.switchToHttp().getRequest();
    if (!user?.email || !admins.includes(String(user.email).toLowerCase())) {
      throw new ForbiddenException('insufficient role');
    }
    return true;
  }
}
```

#### A.4 `src/admin/admin.service.ts` [N]

```typescript
import { BadRequestException, Inject, Injectable, ServiceUnavailableException } from '@nestjs/common';
import { InjectQueue, Queue } from '@nestjs/bullmq';
import { InjectNeo4j } from '../neo4j/neo4j.module'; // provider V1.3 (driver)
import { ONCHAIN_QUEUE } from '../transactions/transaction.processor';

@Injectable()
export class AdminService {
  constructor(
    @InjectQueue(ONCHAIN_QUEUE) private readonly queue: Queue | null,
    @InjectNeo4j() private readonly driver: any,
  ) {}

  private assertQueue(): Queue {
    if (!this.queue) throw new ServiceUnavailableException('queue disabled (QUEUE_ENABLED=false)');
    return this.queue;
  }

  async listFailed(page = 1, limit = 20) {
    const q = this.assertQueue();
    const p = Math.max(1, page), l = Math.min(100, Math.max(1, limit));
    const [jobs, total] = await Promise.all([
      q.getJobs(['failed'], (p - 1) * l, p * l - 1),
      q.getJobCountByTypes(['failed']),
    ]);
    return {
      items: jobs.map((j) => ({
        id: j.id, name: j.name, attemptsMade: j.attemptsMade,
        failedReason: String(j.failedReason ?? '').slice(0, 500),
        data: j.data,
        stacktrace: j.stacktrace?.slice(-1)?.[0] ?? null,
        finishedOn: j.finishedOn,
      })),
      total, page: p, limit: l,
    };
  }

  async listFailedAudit(page = 1, limit = 20) {
    const session = this.driver.session();
    try {
      const skip = (Math.max(1, page) - 1) * Math.min(100, Math.max(1, limit));
      const l = Math.min(100, Math.max(1, limit));
      const res = await session.run(
        `MATCH (f:FailedJob)
         RETURN f ORDER BY f.failedAt DESC SKIP $skip LIMIT $l`,
        { skip: this.driver.int(skip), l: this.driver.int(l) },
      );
      return { items: res.records.map((r) => r.get('f').properties), total: res.records.length, page, limit: l };
    } finally {
      await session.close();
    }
  }

  async retryJob(jobId: string): Promise<boolean> {
    const q = this.assertQueue();
    let job;
    for (const type of ['failed', 'waiting', 'delayed']) {
      job = await q.getJob(jobId);           // Job.getJob(id) est multi-états via Redis
      if (job) break;
    }
    if (!job) return false;
    await job.retry();                       // replace au backoff normal (attempts restants conservés)
    return true;
  }

  async cleanQueue(name: string) {
    const q = this.assertQueue();
    await q.obliterate({ force: true });     // purge complète (jobs + métadonnées)
  }
}
```

```typescript
import { ConfigService } from '@nestjs/config';
import Stripe from 'stripe';
import { InjectNeo4j } from '../neo4j/neo4j.module';

export type SubscriptionTier = 'FREE' | 'PRO' | 'ENTERPRISE';

@Injectable()
export class BillingService {
  private readonly logger = new Logger(BillingService.name);
  private readonly stripe: Stripe | null;
  private readonly enabled: boolean;

  constructor(
    private readonly config: ConfigService,
    @InjectNeo4j() private readonly driver: any,
  ) {
    this.enabled = this.config.get<string>('BILLING_ENABLED') === 'true';
    const key = this.config.get<string>('STRIPE_SECRET_KEY', '');
    this.stripe = this.enabled && key ? new Stripe(key, { apiVersion: '2024-06-20' }) : null;
  }

  assertEnabled() {
    if (!this.enabled || !this.stripe) throw new ServiceUnavailableException('billing disabled');
  }

  async createCheckout(email: string): Promise<{ url: string }> {
    this.assertEnabled();
    const session = await this.stripe.checkout.sessions.create({
      mode: 'subscription',
      customer_email: email,
      line_items: [{ price: this.config.get<string>('STRIPE_PRICE_PRO', 'price_pro_default'), quantity: 1 }],
      success_url: this.config.get<string>('BILLING_SUCCESS_URL', 'http://localhost:4200/billing?ok=1'),
      cancel_url: this.config.get<string>('BILLING_CANCEL_URL', 'http://localhost:4200/billing'),
      metadata: { source: 'clearnet-backend' },
    });
    return { url: session.url ?? '' };
  }

  async status(email: string): Promise<{ tier: SubscriptionTier; customerId: string | null; quotaUsed: number; quotaMax: number }> {
    this.assertEnabled();
    const session = this.driver.session();
    try {
      const res = await session.run(
        `MATCH (u:User {email: $email}) RETURN u.subscriptionTier AS tier, u.stripeCustomer AS customer`,
        { email },
      );
      const tier: SubscriptionTier = res.records[0]?.get('tier') ?? 'FREE';
      const quotaMax =
        tier === 'FREE'
          ? Number(this.config.get<string>('BILLING_FREE_QUOTA', '10'))
          : Number(this.config.get<string>('BILLING_ENTERPRISE_QUOTA', '0')) || Infinity;
      const used = tier === 'FREE' ? await this.countMonth(email) : 0;
      return { tier, customerId: res.records[0]?.get('customer') ?? null, quotaUsed: used, quotaMax };
    } finally {
      await session.close();
    }
  }

  /** Quota mensuel (mois calendaire UTC). Free = 10 tx/mois (BILLING_FREE_QUOTA). */
  async countMonth(email: string): Promise<number> {
    const session = this.driver.session();
    try {
      const start = new Date(); start.setUTCDate(1); start.setUTCHours(0, 0, 0, 0);
      const res = await session.run(
        `MATCH (u:User {email: $email})-[:SENT]->(t:Transaction)
         WHERE t.createdAt >= $start RETURN count(t) AS n`,
        { email, start: start.toISOString() },
      );
      return res.records[0]?.get('n').toNumber?.() ?? 0;
    } finally {
      await session.close();
    }
  }

  /** Applique le changement de tier propagé par le webhook.
   *  Mise à jour idempotente : rejoue sans erreur si l'événement arrive en double. */
  async applySubscription(payload: { customerEmail: string; customerId: string; tier: SubscriptionTier }) {
    const session = this.driver.session();
    try {
      await session.run(
        `MATCH (u:User {email: $email})
         SET u.subscriptionTier = $tier, u.stripeCustomer = $customer`,
        { email: payload.customerEmail, tier: payload.tier, customer: payload.customerId },
      );
      this.logger.log(`tier ${payload.tier} -> ${payload.customerEmail}`);
    } finally {
      await session.close();
    }
  }
}
```

```typescript
import { BadRequestException, Controller, Headers, Logger, Post, RawBodyRequest, Req } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import Stripe from 'stripe';
import { BillingService } from '../billing.service';

/** Endpoint public mais protégé par la vérification de signature Stripe :
 *  constructEvent(rawBody, signature, webhookSecret).
 *  Les événements gérés : customer.subscription.created / .updated / .deleted. */
@Controller('webhooks')
export class StripeWebhookController {
  private readonly logger = new Logger(StripeWebhookController.name);

  constructor(
    private readonly config: ConfigService,
    private readonly billing: BillingService,
  ) {}

  @Post('stripe')
  async handle(@Req() req: RawBodyRequest<Request>, @Headers('stripe-signature') sig: string) {
    if (this.config.get<string>('BILLING_ENABLED') !== 'true') throw new BadRequestException('billing disabled');
    const key = this.config.get<string>('STRIPE_SECRET_KEY', '');
    const secret = this.config.get<string>('STRIPE_WEBHOOK_SECRET', '');
    if (!key || !secret || !sig) throw new BadRequestException('missing stripe config');
    const stripe = new Stripe(key, { apiVersion: '2024-06-20' });

    let event: Stripe.Event;
    try {
      event = stripe.webhooks.constructEvent(req.rawBody as Buffer, sig, secret);
    } catch (err) {
      throw new BadRequestException(`invalid signature: ${(err as Error).message}`);
    }

    if (event.type.startsWith('customer.subscription.')) {
      const sub = event.data.object as Stripe.Subscription;
      const tier = (() => {
        if (event.type === 'customer.subscription.deleted') return 'FREE' as const;
        const item = sub.items?.data?.[0];
        return item?.price?.metadata?.tier === 'enterprise' ? 'ENTERPRISE' : 'PRO';
      })();
      await this.billing.applySubscription({
        customerEmail: (sub.metadata?.email ?? '').toLowerCase() || (sub.customer as string),
        customerId: typeof sub.customer === 'string' ? sub.customer : sub.customer.id,
        tier,
      });
    }
    return { received: true };
  }
}
```

#### D.1 `clearnet-blockchain/contracts/MultiSigWallet.sol` [N]

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.19;

import "@openzeppelin/contracts/access/Ownable.sol";

/// @title MultiSigWallet (2/3) - V1.4 Axe 4
/// @notice Portefeuille de signature déléguée. Le backend (owner 1) soumet la
///         transaction compilée ; 2 confirmations (dont la soumission) requises
///         avant exécution. Aucune clé privée supplémentaire détenue par le
///         backend : les owners 2 et 3 signent hors-ligne (scripts ops).
/// @dev Basé sur le standard Gnosis Safe simplifié (submit/confirm/execute).
contract MultiSigWallet is Ownable {
    uint256 public constant REQUIRED = 2;      // 2/3 (GRACE: ne pas descendre)
    uint256 public transactionCount;

    struct Transaction {
        address destination;
        uint256 value;
        bytes data;
        bool executed;
        uint256 confirmations;
        uint256 timestamp;
    }

    mapping(uint256 => Transaction) public transactions;
    mapping(uint256 => mapping(address => bool)) public isConfirmed;
    mapping(address => bool) public isOwner;
    address[] public owners;

    event Submission(uint256 indexed txId, address indexed destination, bytes data);
    event Confirmation(address indexed owner, uint256 indexed txId);
    event Execution(uint256 indexed txId, address indexed destination);
    event Revocation(address indexed owner, uint256 indexed txId);

    modifier onlyOwner() {
        require(isOwner[msg.sender], "not an owner");
        _;
    }
    modifier txExists(uint256 txId) { require(txId < transactionCount, "tx does not exist"); _; }
    modifier notExecuted(uint256 txId) { require(!transactions[txId].executed, "tx already executed"); _; }
    modifier notConfirmed(uint256 txId) { require(!isConfirmed[txId][msg.sender], "tx already confirmed"); _; }

    constructor(address[] memory _owners) {
        require(_owners.length >= REQUIRED, "owners < REQUIRED");
        for (uint256 i = 0; i < _owners.length; i++) {
            require(_owners[i] != address(0), "zero owner");
            require(!isOwner[_owners[i]], "duplicate owner");
            isOwner[_owners[i]] = true;
            owners.push(_owners[i]);
        }
        _transferOwnership(_owners[0]); // ownership du multisig lui-même (gouvernance)
    }

    function submitTransaction(address destination, uint256 value, bytes memory data)
        external onlyOwner returns (uint256 txId)
    {
        txId = transactionCount++;
        transactions[txId] = Transaction(destination, value, data, false, 1, block.timestamp);
        isConfirmed[txId][msg.sender] = true;
        emit Submission(txId, destination, data);
        emit Confirmation(msg.sender, txId);
    }

    function confirmTransaction(uint256 txId)
        external onlyOwner txExists(txId) notExecuted(txId) notConfirmed(txId)
    {
        transactions[txId].confirmations++;
        isConfirmed[txId][msg.sender] = true;
        emit Confirmation(msg.sender, txId);
        if (transactions[txId].confirmations == REQUIRED) {
            this.executeTransaction(txId); // exécution immédiate à la 2ème signature
        }
    }

    function executeTransaction(uint256 txId) public onlyOwner txExists(txId) notExecuted(txId) {
        Transaction storage t = transactions[txId];
        require(t.confirmations >= REQUIRED, "not enough confirmations");
        t.executed = true;
        (bool success, ) = t.destination.call{value: t.value}(t.data);
        require(success, "execution reverted");
        emit Execution(txId, t.destination);
    }

    function getTransactionCount() external view returns (uint256) { return transactionCount; }
    function getOwners() external view returns (address[] memory) { return owners; }
    function getConfirmations(uint256 txId) external view txExists(txId) returns (address[] memory) {
        address[] memory confirmed = new address[](owners.length);
        uint256 n = 0;
        for (uint256 i = 0; i < owners.length; i++) {
            if (isConfirmed[txId][owners[i]]) { confirmed[n++] = owners[i]; }
        }
        return confirmed;
    }
}
```

```typescript
import { createHmac, timingSafeEqual } from 'crypto';
import { BadRequestException, Injectable, ServiceUnavailableException } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { InjectNeo4j } from '../neo4j/neo4j.module';

/**
 * 2FA MVP (V1.4) : code à 6 chiffres = HMAC-SHA256(SIGNATURE_2FA_SECRET, txId),
 * tronqué (RFC 4226 style). Exige SIGNATURE_2FA_SECRET (≥ 32 car.) en prod ;
 * vide = feature désactivée (règle d'or).
 */
@Injectable()
export class SignaturesService {
  constructor(private readonly config: ConfigService, @InjectNeo4j() private readonly driver: any) {}

  private assertEnabled() {
    if (this.config.get<string>('MULTISIG_ENABLED') !== 'true' ||
        !this.config.get<string>('SIGNATURE_2FA_SECRET', '')) {
      throw new ServiceUnavailableException('multisig signing disabled');
    }
  }

  private codeFor(txId: string): string {
    const secret = this.config.get<string>('SIGNATURE_2FA_SECRET')!;
    return createHmac('sha256', secret).update(txId).digest('hex').slice(0, 6).toUpperCase();
  }

  async request(txId: string, fromEmail: string, dataDescription: string) {
    this.assertEnabled();
    const session = this.driver.session();
    try {
      const res = await session.run(
        `CREATE (s:SignatureRequest {id: randomUUID(), txId: $txId, fromEmail: $fromEmail,
                 dataDescription: $desc, status: 'PENDING', createdAt: datetime()})
         RETURN s.id AS id`,
        { txId, fromEmail, desc: dataDescription },
      );
      return { id: res.records[0].get('id'), otp: this.codeFor(txId) };  // OTP à transmettre hors bande
    } finally { await session.close(); }
  }

  async approve(id: string, otp: string, adminEmail: string) {
    this.assertEnabled();
    const session = this.driver.session();
    try {
      const res = await session.run(
        `MATCH (s:SignatureRequest {id: $id}) RETURN s`,
        { id },
      );
      if (!res.records.length) throw new BadRequestException('request not found');
      const expected = this.codeFor(res.records[0].get('s').properties.txId);
      const ok = expected.length === otp.length && timingSafeEqual(Buffer.from(expected), Buffer.from(otp));
      if (!ok) throw new BadRequestException('invalid OTP');
      await session.run(
        `MATCH (s:SignatureRequest {id: $id})
         SET s.status = 'APPROVED', s.approvedBy = $by, s.approvedAt = datetime()`,
        { id, by: adminEmail },
      );
      return { approved: true, id };
    } finally { await session.close(); }
  }
}
```

```typescript
/** Polling getJobCounts (15 s) : active/waiting/failed sont des états stock. */
export function startQueuePolling(queue: any, metrics: QueueMetrics): NodeJS.Timeout {
  return setInterval(async () => {
    try {
      const counts = await queue.getJobCounts('active', 'waiting', 'failed');
      metrics.active.set({ queue: ONCHAIN_QUEUE }, counts.active ?? 0);
      metrics.waiting.set({ queue: ONCHAIN_QUEUE }, counts.waiting ?? 0);
      metrics.failedGauge.set({ queue: ONCHAIN_QUEUE }, counts.failed ?? 0);
    } catch { /* Redis indisponible : silencieux (dégradation douce) */ }
  }, 15_000);
}
```
